This project has been built to respond to one problematic, Demonstrating Java skills by building a 2D game. 
The goal is to demonstrate all the basic concepts of Java: 

•	Encapsulation

•	Polymorphism 

•	Inheritance 

•	Abstraction 

We choose to make a zombie game in an apocalyptic atmosphere. The game has been divided into three levels and a special bonus. We can kill zombies, change weapon, realising small challenges, to have even more points and maybe win the game… 

Getting Started: 

Choose your characters and start the game! Don’t forget to be quick. The quicker you finish the game, the higher your chance to win! 

Installation: 

You will need to install: 

-	LibGdx
  
-	IntelliJ
  
Because the WHOLE project is built on Java.
